## 📌 Overview

This project is an end-to-end data analysis workflow built using Python.

The project starts by collecting laptop product information through web scraping and then takes the resulting dataset through multiple stages of data preparation and analysis.

### Project Pipeline

```text
Amazon Laptop Data
        ↓
Web Scraping
        ↓
Raw Dataset
        ↓
Data Cleaning
        ↓
Data Preprocessing
        ↓
Exploratory Data Analysis
        ↓
Insights
